# Example projects

Each directory is an independent, illustrative consumer. Copy one to a fresh path before installing the pack; the installer writes ownership metadata and host projections. Its own README gives runnable commands and states which observations remain unknown.

- [Minimal](minimal/README.md): small Markdown and stdlib project, local installer smoke with no optional bots or monitoring.
- [Python API](python-api/README.md): real handler and bounded loopback HTTP behavior with an invalid-input regression.
- [TypeScript web](typescript-web/README.md): strict compiled browser UI and `node:test` behavior, with a separate optional developer compiler.
- [Synthetic run](synthetic-run/README.md): invented source/evidence shapes for a feature, bug, no-fix, unknown, recurrence and rollback. These are teaching fixtures, not accepted live receipts.

The older [config example](config/PRODUCT.md) is a schema/structure fixture. Its signoff text is synthetic and should not be copied as a consumer approval.
