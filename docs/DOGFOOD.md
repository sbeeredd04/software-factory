# The factory working on itself

This repository keeps its own principles, board records, decisions and eval plan under `.software-factory/context/` and `evals/`. The host orchestrator has used them for scoped claims, independent review, integration and recovery. [The dogfood architecture](dogfood/README.md) explains the intended method; this page records observations with their limits. Dates are UTC where a receipt supplies one.

## What the method demonstrated

Claims and checkpoints survived continuation; the owner reconciled run state, Git subjects, dirty paths and review evidence before resuming. Source submissions remained in review until root integration. A private provider diagnostic trial used a guard stub: four intended `gh auth status` attempts were captured with zero escaped invocations after fixture repair. It did not establish real account authentication, and actual doctor can call an available provider CLI.

The [synthetic run example](../examples/synthetic-run/README.md) illustrates bounded observations, deduplication, no-fix and rollback vocabulary. Its invented receipts are separate from the actual host evidence above. No production incident, staging equivalence acceptance, maintainer remote integration, human epic acceptance, Pages deployment or social publication is claimed here.
