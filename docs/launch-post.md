# Launch post draft — unpublished

**Software Factory: BMad plans, the factory ships.**

Software Factory is an MIT-licensed pack of eleven skills and eleven role prompts for Claude Code, Cursor and Codex. Give the active coding host a feature, bug or refactor. Its orchestrator grounds the request in your project, plans at the right depth, staffs bounded work, checks the real diff and evidence, integrates within approved branch scope and escalates consequential risk, unclear authority and reserved owner decisions as needed.

The pack is Markdown plus Python standard-library helpers. It adds no daemon, model service, telemetry or auto-update. BMad Method v6 planning is installed separately with documented pins and supplies the central structured epics and stories. Missing planner capability remains an explicit readiness gap. The project installer previews changes, preserves user files, supports full and skills-only profiles and generates host-specific assets from one canonical source.

To try a local checkout, read the [quickstart](quickstart.md), then work through the [smoke walkthrough](smoke-test.md) on a disposable project. Four [examples](../examples/README.md) show a minimal project, a Python API, a TypeScript web app and a labeled synthetic evidence journey. The [dogfood account](DOGFOOD.md) reports real local checks and failures with exact subjects and limits.

This draft is for a later approved announcement. Before publishing it, verify the actual release URL, final asset, tested installation route, repository visibility, current gate and applicable owner or delegated acceptance. Do not imply remote CI, marketplace availability or a deployed site from a local bundle.
