# Software Factory manual

Start with [quickstart](quickstart.md) for a trusted local checkout and one consumer project. The [smoke walkthrough](smoke-test.md) gives observable commands and outcomes. The [nine workflow diagrams](diagrams/README.md) have Mermaid sources, SVG renders and text equivalents.

## Set up

- [Installation and removal](installation.md): full and skills-only profiles, preservation, doctor and separately provisioned BMad.
- [Configuration](configuration.md): versioned schema, selected governing documents and branch/tracker policy.
- [Host differences](hosts.md): invocation, generated projections and trust limits.
- [Onboarding](onboarding.md): inspect, propose, apply and retain answers.
- [BMad planning](bmad.md): the separately pinned central planning route and honest readiness gaps.

## Deliver and maintain

- [Team](team.md), [agent routing](agents.md) and [review bots](bots.md): best-fit staffing and optional review inputs.
- [Verification](verification.md): case subjects, independent review, integration and effect proof.
- [Evolution](evolve.md): reviewed overlays and capability proposals.
- [Security](security.md), [recovery](recovery.md) and [limits](limitations.md).
- [Dogfood evidence](DOGFOOD.md): dated, source-bound observations and honest gaps.

Four [examples](../examples/README.md) show a minimal local project, a Python API, a TypeScript web app and an explicitly synthetic run.
