# Product request

Software Factory packages a host-owned software delivery method as eleven canonical skills, eleven starting role prompts and standard-library Python helpers. A user supplies an outcome; one orchestrator grounds it in project principles, makes a risk-sized plan, staffs claimed work, requires independent evidence, integrates within authority, proves the resulting artifact and escalates material risk, unclear authority and reserved owner decisions as needed.

The intended user can install into an existing project without losing its files, use separately pinned BMad skills and structured epics/stories when actually available, inspect progress and resume after context loss. The pack must distinguish implementation, local proof, actual integration/effect and applicable owner or delegated acceptance. Its public distribution must be clean and reproducible.

Success is a newcomer completing a real small lap with exact-subject receipts and preserved project bytes. Static host projections and disposable fixtures are useful proof of format and helper behavior; they cannot certify live host loading, remote PR/CI, production monitoring or owner acceptance. See [verification](../verification.md) and [limits](../limitations.md).
